DEPLOYMENT GUIDE

Connect your election

The interface is ready. A deployed contract is required to register voters and record votes.

1. Deploy the contract

  1. Open Remix and create CampusVoting.sol using the source in the downloaded project’s contracts folder.
  2. Compile with Solidity 0.8.24. The version-pinned OpenZeppelin import downloads automatically in Remix.
  3. Open MetaMask, select the intended test network (Sepolia by default), and select your admin account. It needs test ETH.
  4. In Remix’s Deploy & Run panel, select the injected MetaMask provider. Confirm the displayed network and account, then deploy CampusVoting. Approve the transaction in MetaMask.
  5. Copy the deployed contract address. The wallet that deployed it is the preassigned admin account.

2. Add the contract address

Open frontend/script/common.js and replace the placeholder on the first configuration line: 

const contractAddress = "YOUR_DEPLOYED_CONTRACT_ADDRESS";

Record the same address in docs/deployed-contract-address.txt. Use the updated contract included in this project; the original instructor contract lacks the registration and permanent-close functions used by this interface.

If you use another test network, also update chainId, networkName, and rpcUrl in script/common.js. Do not use mainnet or real ETH for this coursework.

3. Run the frontend

Open the project in VS Code. Right-click frontend/html/index.html and choose Open with Live Server, or run: 

npx serve frontend

If using the command above, open /html/index.html at the printed address. Use a desktop browser with MetaMask installed. Public pages read the blockchain without a wallet connection. Registration and voting require MetaMask.

4. Test with three accounts

  1. Admin: add Juan Dela Cruz and Maria Santos for the same position.
  2. Accounts 2 and 3: sign up with their voter wallets.
  3. Admin: verify and authorize both voter addresses, then start voting.
  4. Account 2: log in, select Juan, review, and confirm the vote.
  5. Account 3: log in and vote for Maria.
  6. Try voting again with Account 2. The app and contract must prevent it.
  7. Admin: close voting. Verify the results show one vote each and two votes total. Confirm that reopening is blocked.

Votes and wallet addresses are public blockchain records. This simple classroom project does not implement a secret ballot. The admin must verify one real student per approved wallet.

For the full checklist, limitations, and contribution table, see README.md in the project.
